# Legacy themes

Sonora used to ship Midnight, Forest, Ocean, Rose, Lavender and Amber as built-in themes. They
are no longer part of the app. These files hold their exact colors in the custom theme format.

To use one, copy its file into your themes folder. Settings → Appearance → Open folder opens it.
The theme shows up next to the others straight away.

If one of these themes was selected when you updated, Sonora already put its file in your themes
folder and kept it selected.
